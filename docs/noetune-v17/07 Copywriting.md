# Noetune v17 Copywriting

## Purpose

Copy in Noetune should not explain too much.

It should create a quiet space where the user can notice.

The words should guide, not persuade.

---

## Core Tone

Noetune copy should feel:

- quiet
- simple
- spacious
- non-judgmental
- direct
- gentle

Avoid copy that feels:

- motivational
- therapeutic
- diagnostic
- clever
- salesy
- dramatic

---

## Forbidden Language

Avoid these product words:

- Save
- History
- Archive
- Records
- Analysis
- Insight generated by AI
- Coaching
- Streak
- Achievement
- Level
- Score improvement

These words pull Noetune toward ordinary SaaS, journaling apps, or AI coaching.

---

## Preferred Language

Prefer:

- Journey
- Continue Journey
- Continue
- Active Journeys
- Begin
- Notice
- Feel
- Breathe
- Let it be simple
- When nothing more comes, continue

## Error Copy

Use plain, calm language.

Examples:

Something did not load.

Please try again.

Your Journey could not be continued.

Please try again.

Avoid blame.

Avoid technical language.

---

## Final Rule

If a sentence tries to impress the user, remove it.

If a sentence helps the user notice, keep it.
