# Noetune v17 Localization Guide

## Purpose

This guide defines how Noetune should be translated.

Translate the experience, not the words.

The goal is consistency of feeling across all supported languages.

---

# Core Principle

Users should feel the same product regardless of language.

Translations should preserve:

- quietness
- spaciousness
- neutrality
- continuity
- the Journey philosophy

Literal translation is not required.

Equivalent experience is.

---

# Tone

Every language should feel:

- calm
- simple
- gentle
- non-judgmental
- reflective

Avoid language that feels:

- promotional
- motivational
- therapeutic
- technical
- corporate

---

# Journey Terminology

Always preserve Journey-centered language.

Prefer:

- Journey
- Continue Journey
- Active Journeys
- Begin New Journey

Avoid translating the concept into:

- Save
- History
- Archive
- Records

The value is continuation, not storage.

---

# Measurement

Measurements should feel observational.

Never evaluative.

Avoid wording suggesting:

- success
- failure
- improvement
- performance

The number simply reflects the current relationship.

---

# Theme Translation

Themes are entrances into life.

Do not translate them as menu categories.

Whenever possible, preserve emotional meaning over literal wording.

Theme IDs must never change.

Only labels are translated.

---

# Breathing Screens

Breathing instructions should remain short.

Leave room for silence.

Do not over-explain.

---

# Questions

Questions should invite observation.

Not analysis.

Not reasoning.

Not self-improvement.

---

# Buttons

Buttons should remain short.

Preferred examples:

- Continue
- Begin
- Back
- Nothing More

Avoid long action sentences.

---

# Privacy

Privacy wording should increase trust.

It should clearly communicate:

- No AI analysis
- User writing belongs to the user
- Data exists only for Journey continuation

---

# Consistency

Before release:

- Compare Japanese, English, and Traditional Chinese.
- Confirm they produce the same emotional experience.
- Adjust wording where necessary.

Do not optimize one language independently.

---

# Translation Rule

When choosing between:

- literal accuracy
- emotional consistency

Choose emotional consistency.

Noetune is translated as an experience, not as software.

---

# Final Rule

If a translation sounds like ordinary software, simplify it.

If it sounds like therapy, neutralize it.

If it sounds like marketing, remove the persuasion.

The translation should quietly disappear, allowing the user's own awareness to remain at the center.
