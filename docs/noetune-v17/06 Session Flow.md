# Noetune v17 Session Flow

## Purpose

The session flow is the core of Noetune.

It is not a questionnaire.

It is not coaching.

It is not analysis.

It is a quiet loop in which the user repeatedly notices their relationship with a theme.

---

## Core Structure

Theme
↓
Initial Theme Measurement
↓
Feel 100%
↓
Current State
↓
Measure Current State
↓
Rename
↓
Breath
↓
Ideal State
↓
Breath
↓
Inner Loop
↓
Re-measure
↓
Outer Loop
↓
Final Theme Measurement

---

## Free

Free users can complete the full session.

No core step is removed.

Free is complete.

The Journey ends when the session ends.

---

## Pro

Pro users can continue the Journey.

The system remembers the current Journey position.

The user can return to the same theme and continue from where they left off.

---

## Core Rule

The session must never feel like:

- a test
- therapy homework
- productivity tracking
- AI coaching
- journaling for the sake of journaling

It should feel like a quiet place where life becomes lighter through observation.
