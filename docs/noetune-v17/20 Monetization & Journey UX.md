# Noetune v17
# Monetization & Journey UX

---

# Philosophy

Noetune does not monetize storage.

Noetune monetizes continuation.

Users do not pay to save data.

Users pay to continue their Journey.

---

# Free

A complete session.

Unlimited sessions.

Unlimited Human Core Questions.

No AI.

No advertisements.

Each session becomes a new Journey.

Previous Journeys cannot be resumed.

---

# Pro

Everything in Free.

Unlimited Active Journeys.

Pause a Journey.

Resume from the exact previous step.

Journey continuation.

Nothing is locked behind Pro except continuation.

---

# Active Journeys

Unlimited.

Default order:

Most recently updated.

Sorting:

- Recent
- Lowest initial happiness score
- Question

---

# Completed Journeys

A completed Journey is not history.

It is a question that has become lighter.

Completion means:

The question no longer needs to be measured.

Possible UI:

- Completed Journeys page
- ✓ shown beside completed questions
