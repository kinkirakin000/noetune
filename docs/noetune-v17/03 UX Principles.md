# Noetune v17 UX Principles

## Purpose

The interface should never compete with the user's awareness.

The UI exists to quietly support observation, not to entertain or persuade.

---

# Silence Before Interaction

The product should feel calm.

Every screen should reduce noise.

Nothing should pull attention away from the user's own experience.

---

# One Step at a Time

The user should only face one meaningful action at a time.

Avoid presenting future steps early.

Each screen should answer only one question.

---

# Experience Before Understanding

Users do not need to understand the entire philosophy before beginning.

The experience itself should teach the philosophy.

The interface should reveal meaning through use.

---

# Journey Over Data

Users are not managing records.

They are continuing relationships.

The UI should emphasize:

- Continue Journey
- Active Journeys
- Continue

Avoid emphasizing:

- Save
- History
- Archive
- Records

---

# Themes Are Entrances

Themes are invitations, not categories.

Users should feel they are entering a meaningful question, not selecting content.

---

# Breathing Space

Every transition should leave room to pause.

Silence is part of the experience.

The interface should never rush users toward completion.

---

# Gentle Progress

Progress exists to support continuation.

It must never feel like productivity or achievement.

There are no streaks.

There are no levels.

There are no rewards for speed.

---

# Minimal Language

Use fewer words whenever possible.

The UI should guide without explaining excessively.

If a sentence can be removed without harming the experience, remove it.

---

# Emotional Neutrality

The interface should never judge.

Avoid language implying success, failure, correctness, or improvement.

The product observes.

It does not evaluate.

---

# Leave Space

Not every silence requires text.

Not every screen requires explanation.

Sometimes the best interface is simply enough space to notice.

---

# UX Test

Before adding any UI element, ask:

- Does this help the user notice?
- Does this protect the quietness of the Journey?
- Can this element be removed without harming the experience?

If it can be removed, it probably should be.
