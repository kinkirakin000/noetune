
# Noetune v17 Locale Content

## Purpose

This document defines the core localized meaning for Noetune v17.

The exact UI copy may be adjusted during implementation, but the philosophy must remain consistent across languages.

---

# Language Principle

All languages should preserve the same feeling:

- quiet
- simple
- non-judgmental
- spacious
- Journey-centered

Do not translate literally if the result feels heavy or unnatural.

Translate the experience.

# Terms to Avoid

Avoid direct equivalents of:

- Save
- History
- Archive
- Records
- AI analysis
- Coaching
- Diagnosis
- Achievement
- Streak

If a language requires explanation, explain through continuity rather than storage.

# Final Rule

If a translation sounds like software, make it quieter.

If it sounds like therapy, make it more neutral.

If it sounds like marketing, remove the persuasion.
